== Description ==

This addon allows you to add Google reCAPTCHA Enterprise to your membership registration and login forms.

https://simple-membership-plugin.com/simple-membership-google-recaptcha-enterprise-option/

== Installation ==

1. Upload `swpm-recaptcha-enterprise` folder to the `/wp-content/plugins/` directory
1. Activate the plugin through the 'Plugins' menu in WordPress
