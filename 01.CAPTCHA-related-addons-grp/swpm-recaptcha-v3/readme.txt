Google reCAPTCHA v3 addon for Simple WordPress Membership plugin

== Description ==

This addon allows you to add Google reCAPTCHA v3 to your membership registration form/page. This will prevent spam bot registration (if any).

https://simple-membership-plugin.com/addons-extensions/

== Installation ==

1. Upload `swpm-recaptcha-v3` folder to the `/wp-content/plugins/` directory
1. Activate the plugin through the 'Plugins' menu in WordPress
